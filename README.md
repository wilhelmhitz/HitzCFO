# Wilhelm Hitz

Executive Website built with:

- Next.js 16

- React 19

- TypeScript

- Tailwind CSS 4

- Framer Motion

## Installation

```bash

npm install

npm run dev

```

Production

```bash

npm run build

npm run start

```
